memtest.bin
-----------

This is used to test the SMART Card's Flash memory
and SRAM (usually only by myself before configuration).

IT WILL ERASE ALL THE ROMS ON THE SMART CARD
(apart from the firmware) so you will need to
reinstall the diagROM, Snapload ROM etc after
used.

To use the program, copy it onto your SD Card,
hold ZERO on boot, press Enter to go to the ROM
manager, choose option 8, then option 1 ("load
to $8000 and run") Browse to, and select "memtest.bin"
and follow the instructions that appear when it
runs.

Remember: You'll need to reinstall the ROMs
after using this program.
