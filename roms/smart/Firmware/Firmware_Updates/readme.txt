
FIRMWARE.Vxx

Use the ROM Manager's "Firmware Update" option to load
this file from an SD Card. (To access ROM Manager, hold
SPACE on boot, then press ENTER and choose option 1)

The firmware *update* files in this folder are 12KB in size
since they do not have a default ROM index attached.
