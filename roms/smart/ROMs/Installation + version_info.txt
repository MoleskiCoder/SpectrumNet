
Installing ROMS
---------------

To install ROMs (enable EPROM writes on V1 SMART
Cards by setting DIP Switch 2 to ON - ie: up)

Go to the ROM Manager by first holding ZERO when
powering up the Spectrum. At the ROM index screen,
press Enter and then select option [2] "Write ROM
to a bank" (or option [1] for firmware updates)
Follow the prompts. 

You can either overwrite the existing installed
ROMs or put new ROMs in empty slots - but please
note the following:

* DiagROM needs to go in SLOT B if you want to start
it with the switch on the SMART Card.

* If you put the Snaploader into a bank different
to where the power-on GOTO feature is set, you'll
probably want to change the GOTO to suit (use option 6).
